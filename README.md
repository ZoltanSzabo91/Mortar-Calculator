# Mortar Calculator

Offline-capable mortar fire control and targeting calculator built with HTML, CSS and JavaScript.

Designed for mobile-first usage with tactical UI concepts and configurable mil systems.

---

## Features

- Observer → target calculations
- Mortar → target calculations
- MGRS-style coordinate workflow
- 6400 / 6000 mil system support
- Delta AM correction
- Mobile-friendly UI
- Offline usage
- Theme switching
- Hamburger settings menu

---

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

---

## Usage

1. Enter observer coordinates
2. Enter mortar coordinates
3. Enter target direction and distance
4. Apply Delta AM if needed
5. Press calculate

The calculator returns:
- target coordinates
- mortar azimuth
- mortar distance
